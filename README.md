# Домашнее задание 7. Java Collections

## Как запустить тесты

```
mvn test
```

Нужна Java 17+ и Maven. Эксперимент запускается так:

```
mvn compile
java -cp target/classes collections.CollectionPerformanceExperiment
```

## Где что лежит

- Задание 1: `src/main/java/collections/CustomList.java` и `CustomArrayList.java`, тесты в `src/test/java/collections/CustomArrayListTest.java`
- Задание 2: `src/main/java/collections/CollectionPerformanceExperiment.java`
- Задание 3: `src/main/java/collections/Student.java` и `StudentRegistry.java`, тесты в `src/test/java/collections/StudentRegistryTest.java`

## Результаты эксперимента

Медиана из 5 замеров после 2 прогревочных запусков, по 10 000 элементов.

| Операция | Элементов | ArrayList, мс | LinkedList, мс |
| --- | --- | --- | --- |
| add to end | 10000 | 0.462 | 0.233 |
| add to start | 10000 | 3.658 | 0.606 |
| insert in middle | 10000 | 1.086 | 43.491 |
| get by index | 10000 | 0.023 | 41.356 |
| remove from start | 10000 | 1.560 | 0.600 |
| remove from end | 10000 | 0.044 | 0.914 |

Числа зависят от компьютера и JVM, при другом запуске они будут немного другими.

## Выводы

В ArrayList элементы лежат в одном массиве, поэтому доступ по индексу работает за O(1), а в LinkedList нужно идти по узлам от начала или конца, из-за этого get по индексу получился на порядки медленнее. Вставка в начало и удаление из начала у ArrayList требуют сдвига всех элементов, поэтому там LinkedList быстрее, ему достаточно поменять пару ссылок. Вставка в середину у LinkedList дорогая, потому что сначала надо пройти до нужной позиции за O(n), а сама вставка потом занимает O(1). У ArrayList при вставке в середину сдвигается только половина элементов, и это делается быстрой копией массива. Удаление с конца у ArrayList почти бесплатное, а у LinkedList каждый раз надо отвязывать узел. Добавление в конец быстрое у обоих, но ArrayList иногда расширяет массив и копирует его, а LinkedList на каждый элемент создаёт новый объект узла. Ещё одна причина разницы в локальности данных: элементы массива лежат рядом и хорошо попадают в кэш процессора, а узлы LinkedList разбросаны по памяти. Поэтому нельзя сказать, что одна коллекция всегда лучше, выбирать надо по тому, какие операции выполняются чаще.
